# ADR 0004: Redis and Celery

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
Redis transports Celery jobs; PostgreSQL owns status.

## Alternatives
in-process execution.

## Rationale
standard asynchronous tooling.

## Consequences
at-least-once execution requires idempotency; no business tasks in M0.

## Revisit conditions
complex durable workflow demand.
