# ADR 0012: Bounded, brand-scoped feed discovery

Context: Milestone 2 needs useful discovery without an unrestricted crawler or
unsupported platform API assumptions.

Decision: manually triggered RSS 2.0 and Atom discovery, including YouTube's public
channel Atom feed, uses brand-owned sources. Each run is bounded to 2 MiB and 200
entries. Public HTTPS only; validate every DNS address and pin the connection to a
validated address while preserving TLS hostname verification. Reject redirects,
credentials, nonstandard ports, compressed responses and private/reserved targets.
Parse XML with defusedxml; never fetch embedded links, images or enclosures.

Runs execute synchronously in the initial slice. PostgreSQL records their results;
no business Celery task is introduced before durable job semantics exist. A brand
lock serializes imports and a source cooldown limits outbound requests. A run's
failure is recorded without exposing transport exceptions or secrets.

Candidates deduplicate by normalized URL within a brand, retaining per-source
observations and original URLs. Explicit routing checks edit access to both brands.
Scores use available deterministic relevance, freshness, novelty and user-assessed
source quality; unavailable engagement/share/save metrics remain missing. Scores
are editorial heuristics, not predictions or verified performance. Rights remain
UNKNOWN and cannot be approved through discovery.

Alternatives: background tasks now (rejected until recovery contracts are tested),
generic crawling (unbounded), public global candidate tables (isolation risk).
Consequences: request latency, strict feed compatibility, no automatic polling or
autonomous source exploration yet. Revisit when durable jobs and broader adapters
are implemented. Source policy acknowledgement is required before fetching.

References: RSS https://www.rssboard.org/rss-specification;
Atom https://www.rfc-editor.org/rfc/rfc4287;
SSRF https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html.

YouTube topic URL follows https://developers.google.com/youtube/v3/guides/push_notifications.
Scores preserve null when no configured signal is available. Completed synchronous runs
are not durable jobs; a process crash rolls back the in-flight transaction.
