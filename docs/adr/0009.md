# ADR 0009: Evidence separation

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
OBSERVED, PREDICTED and EXPERIMENTALLY VALIDATED remain distinct.

## Alternatives
merged evidence namespace.

## Rationale
prevent misleading analytics.

## Consequences
definitions and provenance; implementation M7.

## Revisit conditions
equally explicit alternative semantics.
