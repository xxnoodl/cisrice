# ADR 0006: Deterministic-first intelligence

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
rules before optional local model adapters.

## Alternatives
paid inference or mandatory models.

## Rationale
offline utility and bounded cost.

## Consequences
explicit dependency failures; implementation M4.

## Revisit conditions
measured accuracy needs.
