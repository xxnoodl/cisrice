# ADR 0003: PostgreSQL canonical state

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
PostgreSQL owns durable state including jobs.

## Alternatives
SQLite or Redis primary state.

## Rationale
relational integrity and durability.

## Consequences
migrations and backups required.

## Revisit conditions
measured deployment constraints.
