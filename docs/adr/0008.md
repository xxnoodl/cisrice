# ADR 0008: Official publishing and fallback

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
capability-aware official APIs and manual packages.

## Alternatives
browser account automation.

## Rationale
compliance and human control.

## Consequences
approval and remote reconciliation; implementation M6.

## Revisit conditions
official API changes.
