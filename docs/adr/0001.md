# ADR 0001: Local-first Linux-first deployment

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
Linux containers; Windows via Docker Desktop and WSL2.

## Alternatives
native services or cloud-first.

## Rationale
portable offline operation.

## Consequences
Docker required on Windows.

## Revisit conditions
desktop packaging.
