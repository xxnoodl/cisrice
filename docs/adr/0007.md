# ADR 0007: Replaceable production

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
versioned manifests and renderer protocol, initially FFmpeg.

## Alternatives
renderer-specific state.

## Rationale
preserve editing intent across engines.

## Consequences
schema migrations and QC; implementation M5.

## Revisit conditions
advanced editor requirements.
