# ADR 0010: Brand authorization and credentials

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
backend workspace/brand checks and externally keyed encrypted tokens.

## Alternatives
frontend filtering or global credentials.

## Rationale
private data isolation.

## Consequences
authorization before business APIs; implementation M1.

## Revisit conditions
remote multi-tenant deployment.
