# ADR 0005: Content-addressed media

Status: Accepted direction; implementation follows milestones.

## Context
Single-machine local-first multi-brand platform with limited resources.

## Decision
immutable SHA-256 objects with authorized scoped links.

## Alternatives
per-brand duplicate folders.

## Rationale
deduplication and provenance.

## Consequences
implementation M3; authorization on every reference.

## Revisit conditions
remote object storage demand.
